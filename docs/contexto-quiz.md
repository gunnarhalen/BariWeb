# Contexto do Projeto

## 1. Package Manager / Stack

- **Package Manager**: npm (baseado no `package.json`)
- **Stack**:
  - Framework: Next.js 15.5.2 com React 19.1.0
  - Estilização: Tailwind CSS 4
  - UI Components: Radix UI + componentes customizados
  - Backend/Firebase: Firebase 12.2.1
  - Tipagem: TypeScript 5
  - Outras dependências: TanStack React Table, Recharts, Zod, Sonner, Lucide React, Tabler Icons

## 2. Pasta de Testes

**Não encontrado** — Não há pastas ou arquivos de teste identificados no projeto (`**/test*`, `**/__tests__*`, `**/*.spec.*`, `**/*.test.*`).

## 3. Três Arquivos Lidos

1. **`package.json`** — Define as dependências, scripts e configuração do projeto Next.js
2. **`next.config.ts`** — Configurações de build do Next.js (otimizações, TypeScript, formatos de imagem)
3. **`src/types/index.ts`** — Interfaces TypeScript para tipos do domínio (UserProfile, Meal, Patient, NutritionistRequest)
